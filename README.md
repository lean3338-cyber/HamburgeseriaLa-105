# La 105 - Sitio web

HTML + CSS + JS, sin instalar nada. Publicado gratis con GitHub Pages.

- Verlo local: doble clic en `index.html`, o `python3 -m http.server 8000` y abrir http://localhost:8000
- Cuentas, destacados y puntajes compartidos + panel del dueño (`admin.html`): seguir `GUIA-FIREBASE.md`.
- Sin Firebase configurado, funciona en modo demo (datos solo en cada navegador).
- Números de WhatsApp: lista `NUMEROS` en `js/main.js` y botones del cuadro en `index.html`.
